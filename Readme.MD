# Express Beginner API 🚀

**Express Beginner** adalah REST API sederhana menggunakan **Node.js, Express.js, dan MongoDB (Mongoose)** yang dibangun sebagai latihan backend.

> 📌 Aplikasi ini menyediakan API CRUD buku, kategori, dan sistem peminjaman buku.

---

## 📘 API Documentation (Postman)

Dokumentasi lengkap API bisa dilihat di Postman Documenter:

👉 https://documenter.getpostman.com/view/39313336/2sBXVo8nT8

---

## 📦 Fitur

✨ Fitur utama yang tersedia di proyek ini:

- 📚 CRUD buku (create, read, update, delete)
- 🗂️ CRUD kategori
- 📌 Sistem peminjaman dan pengembalian buku
- 📆 Otomatis hitung batas peminjaman (+14 hari)
- 📁 Upload gambar buku
- 🔐 (opsional) Auth jika implementasi ditambah kemudian

---

## 🧠 Tech Stack

Stack yang digunakan:

| Teknologi         | Kegunaan              |
|------------------|----------------------|
| Node.js          | Runtime JavaScript   |
| Express.js       | REST API framework   |
| MongoDB + Mongoose | Database           |
| Multer           | Upload gambar        |
| dotenv           | Konfigurasi env      |
| Cors + cookie-parser | Middleware HTTP |
